\chapter{CLI and SQL Quick Reference}
\index{quick reference}\index{gcloud CLI!commands}\index{bq CLI}\index{gsutil}%
This appendix collects the commands the book's labs actually use, grouped by service, each with a
one-line purpose. It is a lookup table, not a tutorial---each row is taught in context in the
chapter shown in parentheses. All commands assume an authenticated gcloud CLI with the learner
project set (Appendix on environment setup).

\section{Cloud Storage (gcloud storage / gsutil)}
\begin{center}
\footnotesize
\begin{tabular}{@{}p{6.6cm}p{6.2cm}@{}}
\toprule
\textbf{Command} & \textbf{Purpose} \\
\midrule
\texttt{gcloud storage buckets create gs://B -{}-location=US} & Create a bucket (Ch.~0, 1) \\
\texttt{gcloud storage cp LOCAL gs://B/} & Upload a file or object (Ch.~1) \\
\texttt{gcloud storage cp -r gs://B/PREFIX . } & Download a prefix recursively \\
\texttt{gcloud storage ls -r gs://B/} & List objects recursively \\
\texttt{gcloud storage rm -r gs://B} & Delete objects and bucket (careful) \\
\texttt{gcloud storage buckets update gs://B \textbackslash} & Set lifecycle, class, or labels on a bucket \\
\texttt{gsutil versioning set on gs://B} & Enable object versioning (Ch.~1) \\
\texttt{gsutil retention set 30d gs://B} & Apply a retention policy (Ch.~1) \\
\texttt{gsutil -m cp -r SRC gs://B/} & Parallel multi-threaded copy of large trees \\
\texttt{gcloud transfer jobs create ...} & Storage Transfer Service scheduled transfer (Ch.~1) \\
\bottomrule
\end{tabular}
\end{center}

\noindent\texttt{gcloud storage} is the modern, parallel-by-default CLI; \texttt{gsutil} remains
for versioning, retention, and a few legacy flags---the book uses both deliberately (Chapter~0).

\begin{tipbox}
Every \texttt{gcloud} command accepts \texttt{-{}-format=json} and \texttt{-{}-filter=...};
scripting the CLI with JSON output plus \texttt{jq} (or PowerShell's \texttt{ConvertFrom-Json})
turns every lab step into an automatable check---which is exactly how Chapter~24's CI pipelines
verify deployments.
\end{tipbox}
