\chapter{Snowflake SQL Reference for Data Engineers}
\index{SQL reference}\index{cheat sheet}%
This appendix condenses the DDL, DML, system functions, and monitoring views used throughout the book into quick-reference tables. It is organized by task, alphabetically within each group, and cross-referenced to the chapter that teaches the concept. Syntax is simplified for scanning; consult the linked documentation for full grammar \cite{snowflakeDataLoadDocs,snowflakeTasksDocs,snowflakeStreamsDocs}.

\section{Stages, File Formats, and Loading (Chapter 5)}
\begin{center}
\footnotesize
\begin{tabular}{@{}p{5.6cm}p{8.6cm}@{}}
\toprule
\textbf{Command} & \textbf{Purpose / notes} \\
\midrule
\texttt{CREATE STAGE ... URL=... STORAGE\_INTEGRATION=...} & External stage over S3/GCS/Azure with governed credentials \\
\texttt{CREATE STAGE ... DIRECTORY=(ENABLE=TRUE)} & Stage with queryable file-metadata directory table \\

\texttt{VALIDATION\_MODE=RETURN\_ERRORS} & Dry-run validation without writing \\
\texttt{FORCE=TRUE} & Reload files already in load history (duplicates!) \\
\texttt{CREATE STORAGE INTEGRATION ... TYPE=EXTERNAL\_STAGE} & Cloud identity for stages; \texttt{DESC} yields ARN + external ID \\
\texttt{REMOVE @stage / PUT file://... @stage} & Manage internal-stage files \\
\bottomrule
\end{tabular}
\end{center}

\texttt{ACCOUNT\_USAGE.ACCESS\_HISTORY} & Who touched what data, and lineage \\
\texttt{ACCOUNT\_USAGE.LOGIN\_HISTORY} & Authentication audit (MFA, key-pair, anomalies) \\
\texttt{ACCOUNT\_USAGE.TAG\_REFERENCES} & Classification coverage report \\
\texttt{ACCOUNT\_USAGE.STORAGE\_USAGE} & Table and stage storage over time \\
\bottomrule
\end{tabular}
\end{center}

\begin{tipbox}
Latency caveat: \texttt{ACCOUNT\_USAGE} views lag up to a few hours; the \texttt{INFORMATION\_SCHEMA} table functions are near-real-time but windowed. Monitoring that must react in minutes uses information-schema functions; monthly reporting uses account usage.
\end{tipbox}
