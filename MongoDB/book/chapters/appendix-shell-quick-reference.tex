\midrule

\texttt{\$facet} & Many pipelines over one input scan; output $\le$ 16 MB (Ch.~10) \\
\texttt{\$setWindowFields} & Window functions: \texttt{\$rank}, \texttt{\$denseRank}, \texttt{\$derivative}, \texttt{\$avg} over frames; requires \texttt{sortBy} (Ch.~11) \\
\texttt{\$merge} / \texttt{\$out} & Persist results; \texttt{\$merge} with a deterministic key is the idempotent refresh primitive (Ch.~11) \\
\texttt{\$search} / \texttt{\$searchMeta} & Atlas Search; must be the first stage (Ch.~13) \\
\texttt{\$vectorSearch} & ANN retrieval with \texttt{filter} pre-filtering; first stage (Ch.~14) \\
\texttt{\$indexStats} & Per-index usage counters; the drop-candidate evidence (Ch.~12) \\

\section{Atlas Search and Vector Search Definitions}
\index{Atlas Search!index definition}\index{Vector Search!index definition}%
\begin{lstlisting}[language=JavaScript, caption={Atlas Search index: dynamic mapping plus an autocomplete field.}]
{
  "mappings": {
    "dynamic": false,
    "fields": {
      "title": [
        { "type": "string", "analyzer": "lucene.standard" },
        { "type": "autocomplete", "analyzer": "lucene.standard",
          "tokenization": "edgeGram", "minGrams": 3, "maxGrams": 15 }
      ],
      "category": { "type": "token" }
    }
  }
}
\end{lstlisting}

\begin{lstlisting}[language=JavaScript, caption={Atlas Vector Search index: declare every filter field or filters post-apply.}]
{
  "fields": [
    { "type": "vector", "path": "embedding", "numDimensions": 1536,
      "similarity": "cosine" },
    { "type": "filter", "path": "tenantId" },
    { "type": "filter", "path": "publishedAt" }
  ]
}
\end{lstlisting}

\begin{lstlisting}[language=JavaScript, caption={Query stages that consume those indexes (both must lead the pipeline).}]
// Full-text with facet metadata
db.products.aggregate([
  { $search: { index: "default", compound: {
      must: [{ autocomplete: { query: "lap", path: "title" } }],
      filter: [{ equals: { path: "category", value: "computers" } }] } } },
  { $limit: 20 }
])

// Vector retrieval with pre-filtering
db.chunks.aggregate([
  { $vectorSearch: { index: "vec", path: "embedding",
      queryVector: qvec, numCandidates: 200, limit: 10,
      filter: { tenantId: { $eq: "t-42" } } } },
  { $project: { text: 1, score: { $meta: "vectorSearchScore" } } }
])
\end{lstlisting}

\begin{tipbox}
When a command's syntax escapes you, prefer \texttt{db.coll.find(...).explain("queryPlanner")}
over a search engine: the server itself is the ground truth for what it accepts and how it will
execute.
\end{tipbox}
